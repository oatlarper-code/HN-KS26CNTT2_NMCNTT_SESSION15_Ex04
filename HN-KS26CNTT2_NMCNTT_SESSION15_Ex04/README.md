# 4.Yêu cầu đầu ra
- Giải pháp kỹ thuật:
  - OneDrive tích hợp tính năng Files On-Demand cho phép bạn truy cập tất cả các file trong tài khoản OneDrive của mình mà không cần phải tải các file tài liệu, hình ảnh và các file khác về máy tính
  - Không chiếm dụng dung lượng của máy tính mà vẫn có thể xem được hình ảnh và các file tài liệu (file-online thì sẽ phải tải về chỉnh sửa file sang ngoại tuyến thì sẽ mở được tệp)
- Báo cáo dung lượng: 

||Tính năng đồng bộ|Tính năng Files On-Demand
|-|-|-|
Dung lượng Cloud|500GB|500GB
Dung lượng SSD|500GB|chỉ lấy 2-3 GB vào bộ nhớ đệm
Ổ cứng laptop 265GB|Tràn dung lượng dẫn đến lỗi|An toàn lưu trữ thừa 
Ảnh hưởng đến nhà mạng|Tải xuống 500GB sẽ làm treo đường truyền mạng nhà trọ vì hệ thống phải xử lý tệp lớn|Chỉ tải file thiết yếu tối giản toàn bộ dung lượng 500GB

- Chứng minh tính hiệu quả của giải pháp khi dung lượng Cloud lớn hơn dung lượng Local SSD nhiều lần: 
  - Dung lượng cloud có thể mua hoặc chứa nhiều hơn dung lượng của ổ cứng máy tính, sẽ không ảnh hưởng đến máy tính qua đó sẽ vận hành tốt mà không sợ ổ cứng máy tính bị tràn.
